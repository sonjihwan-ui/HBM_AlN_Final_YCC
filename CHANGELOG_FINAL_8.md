- Common liner-recess depth is tied to AlN thickness; SiO2 liner remains below the recessed segment.
- Added nominal 6.0 µm collar OD input and 5.5/6.0/6.5 µm one-dimensional sensitivity in complete study.
- Universal collar AlN is included in the constant-total-AlN-volume budget; rib width is re-solved from remaining AlN area.

- Replaced obsolete TSV–AlN non-contact-gap thermal assumption with segmented SiO2/AlN collar participation.
- Human-facing thermal outputs now report rib-connected collar fraction, baseline SiO2 participation, AlN-collar participation, and recessed-height fraction.
- Restricted AlN thickness to selected 1–2 µm process window.
- Updated integrated workflow/result export version to final-8.0.
- Automated test suite expanded to 61 tests.
